# Example · 影片模式範例（快取，3 幕）

> 一頁版 ＋ 影片模式的最小完整例子。主題：「快取為什麼讓系統變快」。

## 看什麼

| 想看 | 位置 |
|---|---|
| 一頁版骨架（標題 → 一張主圖 → 3 條重點） | 直接開 `index.html` |
| 逐幕預覽 | 開 `index.html?scene=1`，按 ← → 切幕 |
| 場景標記怎麼放 | 搜 `data-scene`：SVG 裡包在沒有 `transform` 的 `<g>` 外層 |
| 旁白怎麼寫 | 搜 `id="video-scenes"`：每幕 ≤ 3 句、每句 ≤ 20 字、數字寫念法 |

## 三幕

| 幕 | 畫面新增 | 旁白重點 |
|---|---|---|
| 1 | 使用者 → 快取（畫線）＋重點 1 | 查詢先問快取 |
| 2 | 快取 → 資料庫（虛線）＋重點 2 | 快取沒有，才查資料庫 |
| 3 | 時間對照（40 vs 800 毫秒）＋重點 3 | 快 20 倍；資料變了要清快取 |

## 出片

```bash
node ../../../scripts/render-video.mjs index.html --out /tmp/cache-explainer.mp4 --burn-subs
```

約 28 秒、1920×1080、H.264＋AAC，旁邊附 `.srt`。規則與參數見 `../../video-explainer.md`。
