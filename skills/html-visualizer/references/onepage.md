# 一頁版（onepage）

> SKILL.md § 輸出階梯 第三階的細節。起手檔：`assets/onepage-template.html`。範例：`examples/video-demo/`。

## 是什麼

一個 1920×1080 的畫面放完一個主題：**標題 → 一張主圖 → 最多 3 條重點**。不捲動。

```
┌─────────────────────────────────────────────────────────┐
│ eyebrow · 日期                                           │
│ 主標：一句話講完主旨                                       │
│ 副標一句                                                  │
├───────────────────────────────────────┬─────────────────┤
│                                       │ 三個重點         │
│          一張主圖（SVG 結構圖）          │ ① 結論一句       │
│                                       │ ② 結論一句       │
│                                       │ ③ 結論一句       │
├───────────────────────────────────────┴─────────────────┤
│ 出處／資料時間                                     日期   │
└─────────────────────────────────────────────────────────┘
```

## 何時用

| 用一頁版 | 不用（走一般頁） |
|---|---|
| 「一頁講完」「一張圖說明」「給老闆一眼看懂」「投影用」 | 內容要分 4 段以上才講得清楚 |
| 會議開場、站會、交接摘要、要貼進簡報或聊天的截圖 | 有待拍板題（走決策頁） |
| 之後要出影片（影片模式的起點） | 讀者需要細節、推導、對照表 |
| 一個機制、一條流程、一個結論 | 多個並列主題 |

判斷不了時，先問自己：**拿掉主圖以外的東西，讀者還能抓到重點嗎？** 能 → 一頁版。不能 → 一般頁。

## 硬規則

| 規則 | 數字 | 誰來驗 |
|---|---|---|
| 1920×1080 不捲動 | 頁面高 ≤ 1080px | `verify.py` 自動跑 `scripts/onepage-check.mjs`（`<html data-layout="onepage">` 就會觸發） |
| 主圖一張 | 1 張 SVG | 人看；畫法照 `structure-diagrams.md`，圖上節點 ≤ 7 個 |
| 重點最多 3 條 | `[data-takeaway]` ≤ 3 | `onepage-check.mjs` |
| 每條重點一句結論 | ≤ 25 字，結論開頭 | 照 `writing-ste.md` 自查 |
| 標題一行 | 主標 ≤ 20 字、副標 ≤ 40 字 | 人看 |

放不下時的處理順序：**砍字 → 減節點 → 縮重點到 2 條 → 拆成兩頁**。不要縮字級硬塞——投影與影片上讀不到。

## 怎麼做

1. 複製 `assets/onepage-template.html`。
2. 改標題區、主圖（SVG）、重點、頁尾出處。
3. 不出影片：刪掉 `#video-scenes` 那段 JSON 即可；`data-scene` 屬性留著無害（平常全部顯示）。
4. 跑 `python3 <skill>/scripts/verify.py <file>`，看「一頁版」那段和印出的 1920×1080 截圖。

## 版面細節

- 主圖格用絕對定位填滿，SVG `preserveAspectRatio="xMidYMid meet"` 等比縮放；SVG 不會把頁面撐高。
- 一頁版 SVG 字級比一般頁大一階（節點名 21、補充 17，viewBox 單位），投影時才讀得到。
- 寬度 < 1100px（手機、平板）自動退回一般捲動頁：一頁的承諾只對桌機與影片。
- 骨架用 `min-height: 100vh` 不用 `height`：內容放不下時頁面會變長，`onepage-check` 量得到；用 `height` 會互相蓋住、量不出來。
- 評論、Session 識別、風格設定與 base-template 相同，照常運作。
