# 簡報模式（slides）

> SKILL.md § 輸出階梯「簡報」那一階的細節。起手檔：`assets/slides-template.html`（10 種版型各一張示範）。實例：`examples/slide-report/`（12 張的真實報告）。

## 是什麼

很多張 1920×1080 的投影片，一張一個重點、不捲動。按 ← → 換頁，像 Keynote 播放。

```
┌──────────────── 1920 × 1080 ────────────────┐
│ 03 / THE PROBLEM  (badge)        ← eyebrow   │
│ 標題一句話，重點詞換色。          ← h2        │
│ 引言一句。                        ← .lead     │
│ ┌──────────┐┌──────────┐┌──────────┐         │
│ │  版型內容：條列／比較／流程／表格…   │ ← 10 種 │
│ └──────────┘└──────────┘└──────────┘         │
│ ▌callout：這張要記住的一句 ▐       ← 可選    │
│ 出處／資料時間 ─────────────────── 03 ← .footer│
└──────────────────────────────────────────────┘
  視窗不是 16:9 → 整張等比縮小、四周留黑邊；手機直拿 → 自動排成一欄往下滑
```

視覺沿用 `examples/slide-report`（使用者選定的預設）：墨綠 ink ＋ teal／mint ＋ peach／lavender、純 sans、eyebrow 加 badge、卡片、深色 callout、頁尾出處＋頁碼。

## 三種產出怎麼選

| 情境 | 用 | 為什麼 |
|---|---|---|
| 要上台報告、投影、開會照順序講、要出 PDF 發給與會者 | **簡報**（本檔） | 一張一個重點，講者控制節奏；列印一張一頁 |
| 一個主題、一張圖講完、要貼進聊天或當影片的一幕 | 一頁版（`onepage.md`） | 只有一個畫面，不用翻頁 |
| 讀者自己讀、要細節、推導、對照表、有待拍板題 | 一般頁（Step 0 的範本） | 可以捲動、展開、就地拍板 |

判斷不了時問：**有沒有人會站在前面一張一張講？** 有 → 簡報。沒有、讀者自己看 → 一般頁。

## 10 種版型與上限

每張 `<section class="slide" data-layout="版型">`。`slides-check.mjs` 會擋「不在 10 種之內」與「超過上限」。

| # | `data-layout` | 用途 | 上限（超過＝拆張） |
|---|---|---|---|
| 1 | `cover` 封面 | 主標、副標、日期／報告人，右欄寫「今天要決定什麼」 | 1 個 h1；主標 ≤ 20 字 |
| 2 | `section` 章節頁 | 換章：章節號＋一句標題＋一句說明 | 不放清單、表格、圖 |
| 3 | `bullets` 重點條列 | 3–5 個並列重點，每條「結論一句＋補充一句」 | 3–5 條（`.bl-list > li`；slide-report 的卡片格、檢查列、三層、履歷欄位也算一條） |
| 4 | `big-number` 大數字 | 一個關鍵數字＋一句結論＋比較基準 | 1 個數字 |
| 5 | `compare` 左右比較 | A vs B、改版前 vs 後；右卡（`.teal`）放建議 | 剛好 2 欄、每欄 ≤ 4 點 |
| 6 | `flow` 流程圖 | 步驟、資料流、有分支或回頭路的流程（SVG，畫法照 `structure-diagrams.md`） | 1 張圖、節點 ≤ 7 |
| 7 | `timeline` 時間軸 | 里程碑、時程；`is-done` 已完成、`is-now` 進行中 | 3–6 個節點 |
| 8 | `table` 表格 | 需要逐格對照的數字或屬性；要強調的列加 `is-hot` | 1 個表、≤ 6 列、≤ 5 欄 |
| 9 | `chart` 圖表 | 資料的形狀（趨勢、對比）；用 @unovis，選圖照 `chart` skill | 1 張圖、旁邊解讀 ≤ 2 條 |
| 10 | `closing` 結論與下一步 | 一句結論、今天拍板的事、行動（誰 · 何時 ＋ 做什麼） | 已拍板 ≤ 3、行動 ≤ 4 |

共通：標題 ≤ 28 字（一行講完）；HTML 文字 ≥ 16px、主要內文 ≥ 22px（設計 px，1920 寬）；圖上文字實際顯示 ≥ 14px。

## 放不下怎麼辦

**拆張，不縮字。** 投影最後一排、影片、手機上都讀不到小字。處理順序：

1. 砍字：每句照 `writing-ste.md`（≤ 25 字、一句一事）
2. 細節移到講者備註（`<aside class="notes">`，按 N 看）
3. 減項：條列 5 條 → 3 條，其餘拆到下一張
4. 拆成兩張：「總覽」一張＋「細節」一張

不要做的事：縮字級、縮 padding 硬塞、把 `.slide` 的 `overflow: hidden` 拿掉（內容會被切掉而不是變安全）。

## 怎麼做

1. 複製 `assets/slides-template.html`。改 `<title>`、操作列的 `.deck-brand`。
2. 每張留一個版型，刪掉不用的示範張；同版型要多張就複製那段 `<section>`。流程圖的 marker id 每張改字尾，整份唯一。
3. 每張寫講者備註 `<aside class="notes">`（播放時按 N 在下方面板看，不會投影出來）。
4. 要出影片：每張加 `data-narration="…"`（沒寫就念講者備註），見下方「影片」。
5. 跑 `python3 <skill>/scripts/verify.py <file>`，看「簡報」那段：每張一行、附 1920×1080 截圖。**逐張看截圖**。

換主題：整段換掉 `:root`（元件只用語意 token）。

## 操作

| 鍵 | 動作 |
|---|---|
| ← → 空白 PageUp PageDown | 上／下一張 |
| Home End | 第一／最後一張 |
| N | 講者備註面板（投影畫面自動縮小讓位） |
| O 或 G | 總覽（縮圖格，點一張回到播放）；Esc 離開 |
| F | 全螢幕 |
| P | 列印／存 PDF（一張一頁，頁面尺寸 1920×1080） |
| 網址 `#3` | 直接打開第 3 張 |

滑鼠停 2.5 秒操作列自動淡出。手機直拿時自動排成一欄往下滑，點一張進播放。

命令列輸出 PDF：`node <skill>/scripts/slides-check.mjs deck.html --pdf deck.pdf`。

## 影片（一張＝一幕）

簡報可以直接交給 `render-video.mjs` 出片，不用另做一頁版：

- `window.__goToScene(n)` 就是切到第 n 張（重播那張的進場動畫）
- 旁白來源優先序：`#video-scenes` JSON → 各張 `data-narration` → 講者備註 `.notes`
- 每張旁白照 `video-explainer.md` 的 3b1b 規則：≤ 3 句、每句 ≤ 20 字、≤ 15 秒
- 張數多時先錄一段試看：`--scenes 2-4`

```bash
node <skill>/scripts/render-video.mjs deck.html --tts say --scenes 1-3 --out ~/Documents/claude-html/2026-10/deck.mp4
```

8 幕上限只管一頁版；簡報張數照內容需要，但一支片超過 3 分鐘就考慮拆。

## 頁面文字

全部照 `writing-ste.md`（八成 ASD-STE100）：短句、一句一事、主動語態、同一個東西一個名字、術語先定義、數字取代形容詞。標題寫成結論（「放棄率下降 37%」），不寫主題（「成果」）。
